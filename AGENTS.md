# DataFlow Manager

## Project purpose
Educational application for managing ETL pipelines.

## Technology stack
- Python 3.12
- FastAPI
- PostgreSQL (later)
- pytest
- uv

## Development rules
- Read the relevant code before making changes.
- For non-trivial tasks, propose a plan first.
- Keep changes small and focused.
- Do not introduce new dependencies without explaining why.
- Add tests for new behavior.
- Run relevant tests after making changes.
- Never claim tests passed unless they actually ran.
- Do not commit or push changes without approval.
- Do not access files outside this repository.

## Architecture
- Keep business logic separate from API routes.
- Prefer simple, maintainable solutions.
- Do not add Docker or a database until requested.

## Communication
- Communicate in Russian.
- Explain significant architectural decisions.
- Summarize changed files and test results.
